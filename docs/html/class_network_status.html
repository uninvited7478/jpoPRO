Detailed Description

Klasa zarządzająca stanem połączenia internetowego.

NetworkStatus odbiera informacje o stanie połączenia od NetworkChecker i emituje sygnały, które są wykorzystywane w QML do aktualizacji interfejsu użytkownika.
