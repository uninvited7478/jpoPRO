\doxysubsection{Detailed Description}
Klasa odpowiedzialna za zarządzanie zapisywaniem i wczytywaniem danych w formacie JSON. 

\doxylink{class_data_manager}{Data\+Manager} umożliwia zapisywanie tablic JSON do plików oraz wczytywanie ich z powrotem. Emituje sygnały w przypadku sukcesu lub błędu, które są używane w interfejsie QML.
